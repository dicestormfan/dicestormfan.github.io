Structuring Social Encounters

In this section, we talk about how to organize a social encounter, and then cover some rules you should use when running one.

Because social encounters use narrative gameplay, not structured gameplay, they're a lot more free-form than combat encounters. This is good for you if you're the GM, because it means you are able to run these encounters as you like, without having to worry about incorporating a lot of rules. However, this also means you have to do more planning in advance, because you don't have the rules to fall back on!
